# 📊 Sales Data Analysis System

A web-based Sales Data Analysis application built using **Python, Flask, and MySQL**.  
This project allows users to record sales, analyze total revenue, view transaction history, and cancel orders through a clean dashboard interface.

---

**🌐 Live Demo**
🔗 https://pure-optimism-production.up.railway.app/

## 🚀 Features

- ➕ Add new sales records
- 📋 View all sales transactions
- ❌ Delete (cancel) an order
- 💰 Automatically calculate total revenue
- 🌐 Clean and responsive UI using HTML & CSS
- 🗄️ Persistent data storage using MySQL

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask  
- **Database:** MySQL  
- **Frontend:** HTML, CSS

## ⚙️ How It Works

1. User enters sales data through a web form.
2. Flask backend processes the request.
3. Data is stored in a MySQL database.
4. SQL queries calculate total revenue dynamically.
5. Results are displayed on a dashboard.
